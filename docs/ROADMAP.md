# Roadmap

## v0.1.0 — public source release candidate

- Git-aware diff analysis and conservative test recommendations
- Static local-import graph for JavaScript/TypeScript
- Human-readable CLI and JSON diagnostics
- High-risk change classification (auth, payments, migrations, configuration)
- No API keys, network calls or telemetry

## Next milestones

1. Independently validate GitHub CI on Linux, macOS and Windows.
2. Support workspaces, TS aliases and common monorepo dependency graphs.
3. Measure test-selection recall on real public repositories with reproducible benchmarks.
4. Publish an npm package and versioned GitHub release after review.
5. Improve integration instructions for Codex, Claude Code and CI.

Roadmap items are not shipping features.
