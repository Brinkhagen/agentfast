# Release checklist

1. Run `npm ci && npm run verify` locally.
2. Confirm GitHub CI passes on Linux, Windows and macOS.
3. Verify README commands against a clean clone.
4. Check documentation claims and demo outputs for accuracy.
5. Create a GitHub release and version tag.
6. Publish to npm only when access, naming and packaging are confirmed.
7. Collect real feedback and publish maintenance updates.

The v0.1.0 source is available, but npm distribution has not been published.
