# Launch kit

AgentFast is an independent open-source project by BRINKHAGEN.

## One-liner

Conservative, explainable test planning for AI-assisted coding. Local-first, no AI API key required.

## Community post

I built AgentFast after running into the same verification problem repeatedly with coding agents: small changes can trigger expensive test suites, while apparently simple changes can break critical workflows.

AgentFast classifies a Git diff and recommends targeted quick feedback only when dependencies are resolvable. High-risk or ambiguous changes default to full testing. It is MIT-licensed, has zero runtime dependencies and never uploads source code.

Feedback, bug reports, real test cases and contributors are welcome.
