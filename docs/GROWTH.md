# Community and adoption

Project success comes from people actually using and maintaining the software.

- Publish a reproducible CLI example, not a performance claim without measurements.
- Share to relevant developer communities where project posts are welcome.
- Invite bug reports and contribution proposals.
- Track genuine visitors, npm downloads, issues and pull requests separately.
- Document every user-reported regression in public issues where appropriate.
- Never inflate traffic, downloads, stars or GitHub activity artificially.

GitHub stars alone are not proof of adoption or ecosystem importance.
