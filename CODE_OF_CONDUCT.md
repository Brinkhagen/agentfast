# Code of Conduct

AgentFast is intended to be a welcoming, professional open-source community.

## Our standards

Be respectful, constructive, inclusive, and considerate. Assume good intent, address technical disagreements with evidence, and help newcomers participate.

Unacceptable behavior includes harassment, threats, personal attacks, discriminatory remarks, revealing private information, sexual harassment, and persistent disruption.

## Scope

These standards apply to issues, pull requests, discussions, releases, and other project spaces, including when representing the project publicly.

## Enforcement

Report concerns privately to **info@brinkhagen.de**, with a link, date, and relevant context. Maintainers may moderate comments, request changes in behavior, temporarily restrict participation, or permanently ban accounts when warranted. Reports will be handled confidentially to the extent practical, fairly, and without retaliation.

This is a concise project-specific code of conduct informed by common open-source community standards.
